PERSONAL DESKTOP APPLICATION

Your files.
Your desktop.

A personal installation of gdirect with a MyGo desktop interface for browsing and managing the owner's Google Drive.

个人使用的 Google Drive 文件管理工具，基于 gdirect 与 MyGo。此站提供应用介绍及隐私说明。

01

Browse & organize

View files and folders, create folders, rename items, and move selected items to Google Drive's trash.

02

Upload & download

Transfer files chosen by the user and save downloads to a local folder. Show transfer progress and local file locations.

03

Remember locally

Keep folder listings, favorites, settings, and local file locations on the user's computer for convenient return visits.

Why Google Drive access is requested

The application requests the Google Drive scope https://www.googleapis.com/auth/drive so it can browse existing files and perform the upload, download, creation, rename, and trash operations selected by its owner. This scope permits broad access to the authorized Drive; access can be revoked in the owner's Google Account.

This OAuth application is maintained by qy4747 for personal use. It uses the open-source gdirect project and a custom MyGo interface. It is not an official Google product or the upstream gdirect project's website.
