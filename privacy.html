PERSONAL APPLICATION · DATA HANDLING

Privacy policy

Effective date: November 5, 2026

This policy covers gdirect, qy4747's personal Google Drive desktop installation with a custom MyGo interface, and this informational website.

1. Who operates the application

The application is operated by qy4747 for the owner's personal use. It is not a public file-hosting service. The maintainer does not operate a separate cloud service that receives Drive files or OAuth credentials from this installation.

2. Information accessed and its purpose

After Google authorization, the application uses the authorized account identifier and OAuth credentials, Drive file and folder metadata (including names, IDs, sizes, modification times, and folder relationships), and the contents of files selected for transfer.

The full Google Drive scope permits viewing, creating, changing, and deleting Drive files. The application uses it to show the owner's existing files, upload and download selected files, create folders, rename items, and move selected items to Drive's trash. Local paths and settings support file selection, transfers, favorites, caching, and opening downloaded files.

3. Storage and diagnostics

gdirect stores OAuth client credentials and account tokens in a local database. The desktop interface stores cached folder listings, favorites, local file paths, and preferences in local configuration files. Downloads are saved to locations selected by the user. These local files are not represented as being encrypted at rest by this policy; their protection depends on the security of the user's computer and account.

A bounded local transfer log can contain file names, sizes, timing, transfer status, errors, and network diagnostics. The interface redacts common token fields and URLs from this log. Optional diagnostics read connection metadata and traffic counters from the user's local proxy software. These application logs and caches are not automatically uploaded to a maintainer-operated server.

4. Network connections and disclosure

The application exchanges authorization and file-management requests with Google using TLS-protected connections and certificate validation. Depending on the selected route, connections may pass through a relay or the user's configured proxy. Network intermediaries can observe connection metadata and traffic volumes; their operation is governed by their own policies. The local proxy bridge forwards encrypted TLS traffic without installing a certificate or decrypting file contents.

Google handles account and Drive data under its own policies. This application does not sell Google user data, use it for advertising, or use it to develop, improve, or train generalized artificial-intelligence or machine-learning models. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention, deletion, and access revocation

Local credentials, cached metadata, preferences, and downloaded files remain on the user's computer until removed by the user or the relevant application. The desktop transfer log is overwritten when a new transfer begins. Cloud files remain subject to the owner's Google Drive actions and Google's retention rules.

The owner can revoke authorization through Google Account third-party connections. Local credentials and cached data can be removed separately using gdirect's account-management facilities or by deleting the relevant local files. Revocation does not itself erase downloaded files or cloud files. Moving an item to Drive's trash follows Google's trash and recovery behavior.

6. This website

This website contains static application information. It has no application login, upload form, analytics script, advertising, or application-set cookies, and it cannot read Drive files or local application credentials. GitHub Pages hosts the site and may process technical access information such as IP addresses under the GitHub Privacy Statement.

7. Changes and contact

Changes to these data-handling practices will be reflected on this page with an updated effective date. Questions can be directed to the maintainer through the gdirect-pages repository. Do not include credentials or private files in a public issue.
